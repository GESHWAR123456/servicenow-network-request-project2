# Automated Network Request Management – ServiceNow Project

##  Project Overview

This project automates network service requests using ServiceNow. It allows users to request new network connections or relocation through a catalog item, which triggers approval workflows and task automation.

---

##  Features

* Service Catalog Request Form
* Automated Approval Workflow
* Task Assignment to Network Team
* Real-time Status Tracking
* End-to-End Request Lifecycle Automation

---

##  Modules Used

* Service Catalog
* Flow Designer
* Request Management (REQ, RITM, SCTASK)
* Workflows / Approvals

---

##  Workflow

1. User submits network request
2. Request (REQ) is generated
3. Approval is triggered
4. Task assigned to network team
5. Request fulfilled and closed
